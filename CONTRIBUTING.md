# Contributing to Wi Studio Open Lab

Thank you for making the public contract clearer or more useful.

1. Open an issue before a large change.
2. Keep pull requests focused and explain the user or developer problem.
3. Add or update tests and documentation with behavior changes.
4. Do not submit private data, unreleased product material, copied platform assets or secrets.
5. Use English for the primary change description; Vietnamese context is welcome in a follow-up section.

All contributions are reviewed under the repository license and the evidence boundary described in the README.
